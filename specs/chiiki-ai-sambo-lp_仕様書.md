## 1. プロダクト概要

### 1.1 目的
「地域AI参謀」というFromToの中長期ビジョンを世に問う独立LPを新設する。既存47Connect LP（営業企業向け・ROI訴求）とは明確にトーン・ファネル目的を分離し、**ビジョン共感・対話開始**を主成果とする。

### 1.2 解決する課題
- 既存47Connect LPは企業向けROI訴求に最適化されており、自治体・地域企業・メディア・投資家がアクセスしても「これは自分たち向けではない」と離脱する構造。
- 「地域AI参謀」という上位概念（B2G2B2Cの統合戦略）を語る公式チャネルが現状存在せず、メディア・投資家・自治体首長クラスへの説明資料が口頭・PDFに依存している。
- 製品寄附仲介・越境派遣・47Connectの3事業が「個別プロダクト」としてバラバラに見えており、**一本のビジョンに束ねる物語装置**が不足。

### 1.3 ターゲット読者（3層）

| 層 | 想定読者 | 来訪動機 | 期待アウトプット |
|---|---|---|---|
| **A. 自治体層** | 首長・副市長・政策企画課・DX推進課 | 「自治体AI参謀って何？」「FromToってどんな会社？」 | 意見交換・共同検討の打診 |
| **B. 地域企業層** | 地銀・地域商社・大手企業の地域支店・地方創生部署 | 「B2G2Bスキームの提携先を探している」 | 連携相談・パートナー打診 |
| **C. メディア・投資家層** | 地方創生系記者・VC・公的金融・SIB関連投資家 | 「中長期ビジョンを知りたい」「FromToの社会的位置付け」 | 取材・資料請求・対話 |

### 1.4 ファネル目的・成功指標（KPI）

| 指標 | 目標値（公開後3ヶ月） | 計測方法 |
|---|---|---|
| ページ訪問数 | 月間 500UU 以上 | GA4 |
| 平均滞在時間 | 3分以上 | GA4 |
| お問い合わせフォーム送信 | 月10件以上（3層合計） | フォーム送信イベント |
| 47Connect LP への送客 | 月20クリック以上 | アウトバウンドクリック計測 |
| 質的指標 | 自治体首長・メディアからの個別問合せ獲得 | CRM手動記録 |

### 1.5 既存47Connect LPとの差別化

| 比較軸 | 既存47Connect LP (index-b.html) | 新規 地域AI参謀 LP (chiiki-ai-sambo.html) |
|---|---|---|
| **主役** | 47Connect / 自治体AI参謀（営業企業向けプロダクト） | 地域AI参謀（FromToのビジョン） |
| **トーン** | ROI訴求・営業稟議・コンサル代替 | ビジョン・ピッチ・社会的物語 |
| **CTA** | β版応募・無料相談（即決訴求） | 対話・資料請求・意見交換（関係構築） |
| **読者** | BtoG企業の決裁者層 | 自治体・地域企業・メディア・投資家 |
| **比較対象** | 自治体コンサル（月50-100万円） | （比較対象を出さず、ビジョン提示） |

## 3. ナラティブストーリーフロー

### 3.1 論理的流れ

```
S01 HEADER
  ↓
S02 HERO（ビジョン提示）
  ↓
S03 INTRO（なぜ今このビジョンが必要か = 社会課題提起）
  ↓
S04 CONCEPT（地域AI参謀の定義 = 答えの提示）
  ↓
S05 MODE-1 自治体参謀モード（設計フェーズ）
  ↓
S06 MODE-2 地域展開モード（実装フェーズ）
  ↓
S07 NARRATIVE-FLOW（2モードの統合ストーリー）
  ↓
S08 EXISTING-3-BUSINESS（既に動いている3事業 = 絵空事ではない証拠）
  ↓
S09 TRACK-RECORD（実績数字）
  ↓
S10 WHY-FROMTO（独自性根拠）
  ↓
S11 FOR-WHOM（読者別の関わり方）
  ↓
S12 FAQ（疑問解消）
  ↓
S13 END-CTA（2経路の対話誘導）
  ↓
S14 FOOTER
```

### 3.2 読者の感情曲線

| 段階 | セクション | 読者の感情 | 設計意図 |
|---|---|---|---|
| 共感 | S02-S03 | 「確かに地域課題はある」 | 社会文脈で共通基盤を作る |
| 理解 | S04-S07 | 「なるほど、こういう構造で解決するのか」 | 2モード×統合フローでビジョンを腹落ち |
| 納得 | S08-S10 | 「絵空事ではない、既に動いている」 | 既存3事業・実績・FromToの独自性で信頼形成 |
| 行動 | S11-S13 | 「自分に関係がある、相談してみよう」 | 3層別の入口提示でCV |

### 3.3 既存3事業の自然な織り込み方

S08で既存3事業を初めて明示。それぞれを以下の役割でビジョンに統合：

- **47Connect（自治体AI参謀）** = S05「自治体参謀モード」の**現在実装中の主力プロダクト**として紹介。「自治体導入のご検討は47Connectへ」CTAから既存LPへ送客。
- **製品寄附仲介（144件/106自治体）** = S06「地域展開モード」の**初期実装・物資導線**として紹介。実績数字でビジョンの実在性を担保。
- **R&D型越境派遣** = S06「地域展開モード」の**深層実装・人材導線**として紹介。中長期の人材投入チャネルとして位置付け。

**重要原則**: 既存3事業をプロダクトとして売り込まない。あくまで「地域AI参謀ビジョンの既実装ピース」として軽く触れる。

## 4. セクション・コンポーネント定義（ワイヤーフレームレベル）

### S01 HEADER
- **構成要素**: ロゴ「FromTo」/ ナビ（コンセプト・2モード・既存事業・お問い合わせ）/ ヘッダーCTA「お問い合わせ」
- **流用元**: index-b.html `.header` クラス完全流用
- **新規**: 「47Connectをご検討の方は こちら」サブリンク追加
- **状態**: スティッキー、モバイル時はナビ折り畳み（既存と同様）

### S02 HERO
- **構成要素**: H1「地域AI参謀」+ サブコピー + 3層向け一言CTA + ビジュアル要素
- **流用元**: index-b.html `.hero` クラス（深青ベタ塗り背景）
- **新規**: ビジュアルは既存LPの「mock UI」ではなく**コンセプト図**（自治体→地域への広がりを示す抽象図 or SVGダイアグラム）
- **CTA**: メインCTA「ご相談・お問い合わせ」/ サブCTA「コンセプトを読む（#concept への内部リンク）」
- **コピー方針**: 営業フックなし、ビジョン提示型。「予算書が出た当日」のような営業ROIコピーは禁止

### S03 INTRO（why now）
- **構成要素**: アイブロー「Why Now」+ 見出し + 3〜4段落本文
- **流用元**: 通常セクション（白背景・`.h-section` `.lede`）
- **コンテンツ要素**: 人口減少・財政逼迫・自治体DX遅延・地域経済縮退の4文脈から選定

### S04 CONCEPT
- **構成要素**: アイブロー「Concept」+ 見出し「地域AI参謀とは」+ 定義図 + 一言コピー
- **流用元**: `.section-head.center` + 中央配置レイアウト
- **新規**: 2モード（自治体参謀モード／地域展開モード）を視覚化したダイアグラム（既存LPの`.layer-stack`を参考に再構成）
- **キーコピー**: 「自治体を起点に、地域へ広がるAI戦略パートナー」

### S05 MODE-1 自治体参謀モード
- **構成要素**: モードタグ + 一言「自治体の右腕」+ 6機能カード + 47Connect導線
- **流用元**: index-b.html `.sambo-grid` カード構造を流用
- **6機能**: 政策立案 / 施策設計 / 議会資料 / 他自治体事例分析 / 民間連携提案 / KPI設計
- **導線**: 「このモードを実装しているのが **47Connect** です」→ 既存LPへリンク

### S06 MODE-2 地域展開モード
- **構成要素**: モードタグ + 一言「地域に広げるエンジン」+ 5機能カード + 既実装事業への導線
- **流用元**: S05と同じカード構造
- **5機能**: 地域企業向け施策展開 / B2G2Bスキーム構築 / 住民向けサービス導線設計 / 利用促進支援 / 地域経済活性化支援
- **導線**: 「このモードの初期実装が **製品寄附仲介**、深層実装が **R&D型越境派遣** です」

### S07 NARRATIVE-FLOW
- **構成要素**: 「設計→実装」フロー図 + キャッチコピー
- **流用元**: `.flow` セクションの構造（フロー図）を簡略化して流用
- **キーコピー**: 「絵に描いた政策で終わらせないAI」

### S08 EXISTING-3-BUSINESS
- **構成要素**: 3事業カード（47Connect / 製品寄附仲介 / 越境派遣）
- **流用元**: `.really-grid` または `.sambo-grid` の3カラム構造
- **新規**: 各カードに「対応モード」タグ（自治体参謀 / 地域展開）を表示
- **導線**: 47Connectカードのみ「詳しく見る」ボタン → index-b.html へ

### S09 TRACK-RECORD
- **構成要素**: 数字カード3〜4枚（106自治体 / 144件寄附 / 2億円超 / β版応募XX社 等）
- **流用元**: index-b.html `.roi-stats` 構造を流用
- **除外**: 越境派遣の実績数字は **公開しない**（CEO決裁2026-05-07・Q7: 公開可能実績無し）

### S10 WHY-FROMTO
- **構成要素**: 3つの根拠カード（実績の厚み / 関係性の信頼 / 技術基盤）
- **流用元**: index-b.html `.why-pillars` 完全流用（深青背景）

### S11 FOR-WHOM
- **構成要素**: 3層タブ（自治体 / 地域企業 / メディア・投資家）+ 各層別の問いかけ文
- **流用元**: index-b.html `.role-tabs` `.role-pane` 構造流用（JSタブ切替）
- **代替案**: タブが煩雑ならば3カラム並列表示

### S12 FAQ
- **構成要素**: details/summary形式のFAQ 5〜7問
- **流用元**: index-b.html `.faq-list` `.faq-item` 完全流用
- **必須質問**:
  - 「地域AI参謀」と「自治体AI参謀」は何が違いますか？
  - 47Connect との関係は？
  - 「地域AI参謀」は商品名ですか？
  - 自治体ですが、何から相談すればよいですか？
  - 地域企業ですが、提携の可能性はありますか？
  - メディア取材は受け付けていますか？

### S13 END-CTA
- **構成要素**: 深青背景 + 2CTA + リード文
- **流用元**: index-b.html `.end` セクション流用
- **2CTA**:
  1. 「ご相談・意見交換」（メインCTA・47Connect用Googleフォーム流用 / 必要時に項目追加・CEO決裁2026-05-07・Q5）
  2. 「自治体導入のご検討は47Connectへ」（テキストリンク・既存LPへ）
- **削除**: 旧3CTAの「資料請求」は **不要**（CEO決裁2026-05-07・Q6: 現時点で配布物無し）

### S14 FOOTER
- **構成要素**: コピーライト + 既存3事業リンク
- **流用元**: index-b.html `.foot` 流用
- **商標注記**: **不要**（CEO決裁2026-05-07・Q1: 商標出願未着手のためスキップ）

### ローディング・エラー・空状態
- **基本不要**: SPAではなく静的HTML。フォーム送信のみ外部Googleフォーム遷移を想定（埋め込みなし）。

## 5. 非機能要件

### 5.1 レスポンシブ対応
- **PC**: 1200px固定 wrap、最大1440pxまで自然拡張
- **タブレット**: 760px〜1199px、2カラム→1カラム切替
- **モバイル**: 〜759px、全1カラム・ナビ折り畳み・スティッキーCTA表示
- **基準**: 既存 index-b.html のブレイクポイント `760px` `860px` `920px` `980px` を踏襲

### 5.2 アクセシビリティ
- **目標**: WCAG 2.1 AA 準拠
- **必須項目**:
  - すべての画像に`alt`属性
  - `<button>`にaria-label / `<a>`に明示テキスト
  - コントラスト比4.5:1以上（既存CIカラーは要検証）
  - フォーカスリング表示
  - キーボードナビゲーション全機能対応
  - FAQはdetails/summaryでセマンティック実装

### 5.3 パフォーマンス
- **LCP**: 2.5秒以内
- **CLS**: 0.1以下
- **FID/INP**: 200ms以内
- **画像**: WebP優先、loading="lazy" 適用（HERO以外）
- **フォント**: Google Fonts preconnect、display=swap
- **JS**: タブ切替の最小実装のみ（既存LPと同等）

### 5.4 SEO
- **title**: 「地域AI参謀 — 自治体を起点に地域へ広がるAI戦略パートナー｜FromTo」（60字以内）
- **meta description**: 130字以内、ビジョンと3層読者の入口を含む
- **OG**: og:image (1200x630)、og:type=website、og:locale=ja_JP
- **構造化データ**: Organization schema (FromTo) + WebSite schema
- **canonical**: 設定必須（既存47Connect LPとのcontent duplicationを回避）
- **robots**: index, follow
